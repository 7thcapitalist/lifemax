# Users

## Primary user

The founder, as a single-owner personal system — not built for "everyone"
yet. There is no multi-tenant or public-user design intent right now.

## Jobs to be done

- Define the kind of person I want to become, in domains that matter to me
  (defaults: Builder, Body, Knowledge, Academics, Capital, Relationships,
  Life Lived/Adventure, Recovery — not a fixed ontology).
- Pick a small set of current quests and see progress reflected honestly,
  without being reduced to one score.
- Get a weekly reflection that notices imbalance (over-indexing one domain
  at the cost of the others) without becoming another guilt machine.

## Sensitivities

This is personal, behavioral, self-assessment data — habits, mood, quest
completion, reflections. It is not health, financial, or medical data by
design (see VISION.md non-goals), but treat it with the same care: it stays
local, `AI_MODE` and telemetry stay disabled by default, and any future
external integration (calendar, health, finance) needs an explicit decision,
not a silent default flip.
