# Claude Code — LifeMax

Use `AGENTS.md` as the shared engineering contract. Read `docs/PRODUCT.md` before proposing features.

When working in this repository:
- Think as a product-minded founding engineer, not a ticket taker.
- Challenge features that add tracking burden without improving the core loop.
- Preserve the distinction between “evidence” (what happened) and “meaning” (what the user wants it to mean).
- Prefer one excellent end-to-end user loop over many disconnected integrations.
- Keep UI language game-like but not childish.
- Do not invent health or financial interpretations from raw data.
- Before large edits, state the product hypothesis being tested.
