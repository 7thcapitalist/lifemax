# Project State

Last updated: 2026-08-27

## Product state
LifeMax is at v0. The current hypothesis is that a multidimensional character sheet + quests + balance feedback can make personal progress feel more motivating and less guilt-driven than a conventional productivity tracker.

## Built
- Responsive character dashboard
- Eight default life domains
- Weekly quest list
- Quest completion interaction
- Balance warning concept
- Weekly reflection card
- Life Lived side quest
- Product, roadmap, architecture, and agent instructions

## Not built
- Authentication
- Database
- Custom onboarding
- Real AI game master
- Calendar, GitHub, health, or finance integrations
- Notifications

## Current experiment
Use the product manually before integrating data. We need to learn whether opening the character sheet and completing quests feels useful enough to become a habit.

## Next best tasks
1. Run the app locally after installing dependencies and fix any build/type issues.
2. Make player identity and quests editable without adding a backend.
3. Add a lightweight Sunday review flow.
4. Use personally for seven days and record friction.

## Open product questions
- What exactly earns XP without encouraging gaming?
- Should domain levels represent cumulative identity, recent momentum, or both?
- How should the game master distinguish ambitious weeks from unhealthy imbalance?
- Which first integration reduces manual effort the most: Calendar, GitHub, or health?
